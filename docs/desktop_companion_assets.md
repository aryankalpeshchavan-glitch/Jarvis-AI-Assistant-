# JARVIS Desktop Companion — Asset Documentation

This document tracks all external visual assets, 3D models, sprite sheets, and VFX references used in the construction of the JARVIS Desktop Companion. 

**Policy:**
- Prefer CC0 or CC Attribution licenses compatible with our use.
- Marvel / Iron Man assets are used strictly as **PROTOTYPING / RESEARCH REFERENCES** and are NOT shipped as production assets unless they are original reimplementations inspired by the same design language.
- The J.A.R.V.I.S visual identity must remain original, cinematic, and premium.

## 1. Sci-Fi Essentials Kit
- **Source:** [Quaternius](https://quaternius.itch.io/sci-fi-essentials-kit)
- **License:** CC0 (Public Domain)
- **Usage:** Legal source for generic sci-fi robotic components, holographic bases, and drone geometry prototyping.

## 2. Hologram FX
- **Source:** [Binbun3d](https://binbun3d.itch.io/hologram-fx)
- **License:** CC0
- **Usage:** Core VFX shaders/techniques for the holographic AI Orb, scanlines, and distortion effects.

## 3. Cathode Terminal / Hologram VFX
- **Source:** [Godboyhappy](https://godboyhappy.itch.io/cathode-terminal-glitch-hologram-vfx)
- **License:** Free sampler (Personal/Commercial use permitted)
- **Usage:** Restrained use for system activation pulses and subtle terminal scanlines. (Glitch/noisy cyberpunk elements are excluded).

## 4. Reference: Iron Man Mark 85 Nano Tech Arc Reactor
- **Source:** [Sketchfab](https://sketchfab.com/3d-models/iron-man-mark-85-nano-tech-arc-reactor-free-7686cfc26b68477cb64d33a467c9f9bf)
- **License:** CC Attribution
- **Usage:** **REFERENCE ONLY**. Used to study mechanical containment rings, faceted energy nodes, and stark-style engineering geometry to design our original Arc Core.

## 5. Reference: Rigged Industrial Drone
- **Source:** [Sketchfab](https://sketchfab.com/3d-models/industrial-drone-rigged-and-animated-7ce7efc6c061403087a783ee84d34bef)
